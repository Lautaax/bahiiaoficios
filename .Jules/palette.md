## 2026-10-01 - Dynamic ARIA labels for toggle states\n**Learning:** When dealing with buttons that toggle between states (like a chatbot open/close button), it's important to provide dynamic aria-labels (e.g. `aria-label={isOpen ? 'Cerrar asistente' : 'Abrir asistente'}`) rather than a static one so screen reader users understand the current action available.\n**Action:** Always check if a button represents a toggleable state and apply dynamic `aria-label` attributes accordingly.
